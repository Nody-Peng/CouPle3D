# Sunnyside 小鎮改版

目前啟用 `scripts/sunnyside_town_2d.gd`。原有 `coastal_scenery_2d.gd` 和 `coastal_details_2d.gd` 留存，但不再由主場景載入。

## 本輪範圍

- 使用 Sunnyside 圖集的屋瓦、木牆、門窗、植栽、圍籬及碼頭模組。
- 戶外共用 48 像素格網，路網連接四棟小鎮建築與車站。岸線以格網形成凹凸，碰撞跟隨相同水域資料。
- 草地採用圖集變體，道路有草緣及轉角；海水有原圖集紋理和動態反光。
- 每棟建築資料有穩定 ID、入口、位置和屋頂色組，供後續接入獨立室內。
- 室內與原有存檔保留；仍支援 1.5 倍跟隨及全景模式。

## 入口

| 建築 | 目前行為 | 尚未完成 |
| --- | --- | --- |
| 共同之家 | 返回原本可走動的室內 | 室內統一為 Sunnyside 材質與比例 |
| 綜合商店 | 開啟既有家具商店面板 | 獨立可走動的商店室內 |
| 咖啡與桌遊 | 開啟既有默契卡面板 | 咖啡廳室內及更多桌遊 |
| 回憶郵局 | 開啟共同日記面板 | 郵局室內、信件與禮物系統 |
| 海風車站 | 明確告知尚未開放 | 車站室內與旅行 |

這輪是小鎮底層替換，不代表所有建築室內和完整企劃已完成，也尚未部署到雲端。線上商店、日記和默契卡沿用現有登入需求。

## 試玩

執行根目錄 `start-home-2d.cmd`。WASD 移動，E 或家具附近的動作按鈕互動；方向鍵及 Enter 控制第二個本機角色。從住家東側出口往右走進入小鎮。更新檔案後，已經開著的舊遊戲視窗須關閉再啟動才會載入新版。

## 驗證

`tools/verify-home-2d.gd` 包含室內房門、鏡頭與互動按鈕、小鎮三個功能入口、建築碰撞、主要道路、海岸和碼頭邊界。`tools/capture-couple-home-2d.gd` 產生三區及小視窗的截圖。
