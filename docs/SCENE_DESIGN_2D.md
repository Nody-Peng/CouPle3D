# 私人雙人家園：場景配置

## 視覺與素材

室內主要使用 PixelSpaces 的獨立家具、廚具、收納及浴室素材；保留 House Interior 的電視與椅子。戶外使用 Sunnyside 的樹木、植栽、圍籬、水面和小舟。餐點使用 Pixel Platter。

自製補件為 Godot 原生繪圖：連續廚櫃、磁磚防濺牆、砧板、瀝水架、雙人床、床頭櫃、木地板、布織地毯、園藝桌、晾衣架、棚架、遮陽傘、休憩攤架、碼頭安全用品。共用灰綠、珊瑚粉、木色及淺灰白；原始素材檔未覆寫。

素材仍保留各自授權。這個版本的使用範圍是兩人私人遊玩，不能據此推定已取得公開商業發行的所有授權。

## 行為與邊界

- 沿用原本室內、庭院、海邊三個相鄰畫面，不新增大型世界或帳號系統。
- 保留五個房間門口及東向主通路。大型家具、廚檯、樹幹、園藝桌和休憩設施有碰撞。
- 水面不可步行；碼頭可通行，末端保留合照入口。
- 流理台的洗手及爐台熱湯提供短暫水流、熱氣與文字回饋。這是本機場景演出，不是可同步的烹飪或物品製作系統。
- 室內便條只在家中顯示；線上互動提示只選取自己的角色。
- 遠距離部署仍需接上實際主機與 HTTPS 網址；本次沒有進行雲端發布。

## 驗證

- `tools/verify-home-2d.gd`：五個房門、戶外連通、海岸及碼頭邊界、便條視窗、廚房接近點與動作、家具碰撞、跨區 HUD。
- `tools/capture-couple-home-2d.gd`：1440 x 900 的三區畫面、960 x 600 的室內與海邊、水流及熱氣演出截圖。
- `tools/inspect-scene-assets.gd`：原始圖集局部放大檢視，僅為開發工具，不改動素材。
- `tools/verify-home-network.mjs`：兩個 Godot HTTP 客戶端登入、cookie、便條及聊天同步。
- `node --test tests/home2d.test.mjs tests/store.test.mjs`：32 個測試。
