## 已確認的範圍

- 平台：Windows 桌面版。
- 引擎：Godot 4。
- 畫面：固定俯視 2D 像素風。
- 玩家：你與男朋友兩人，不做公開社交服務。
- 原則：低壓、沒有登入懲罰，所有親密互動都可拒絕。
- 主要美術：Sunnyside World 角色與世界色彩、House Interior 家具。
- UI：深墨色、奶油色、珊瑚紅、藍綠色的統一復古介面。
