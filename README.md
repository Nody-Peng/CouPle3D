# 心動之城 / Together City

可在瀏覽器遊玩的雙人 3D 情侶遊戲雛形。Godot 負責園區、住宅與角色；Web 介面與 Node.js 後端負責帳號、持久化、共同銀行、布置及海戰棋。

## 立即啟動

需要 Node.js 22 以上。此工作區已備妥 Web 匯出檔。

雙擊 `start-web.cmd`，或在專案目錄執行：

```powershell
node server/server.mjs
```

開啟 http://localhost:8787 。測試碼為 `together-local`；兩位角色為「小晴」與「阿澄」。請用一般視窗和無痕視窗，或兩個不同瀏覽器分別登入，避免共用登入 Cookie。每人初始 120 遊戲幣。

手機與電腦連上相同 Wi-Fi 後，可執行 `powershell -ExecutionPolicy Bypass -File tools/start-web.ps1 -Lan`，再用手機開啟 `http://電腦的區域網路IP:8787`。建議橫向操作；網路需允許連入 8787 埠。

- 兩人都能布置，編輯鎖一次允許一人操作；家具格線放置、旋轉、取消、儲存與復原上一版。第一版限客廳、遊戲室、書房指定區域，避免堵住走道。
- 6 × 6 海戰棋，三艘船長度為 3、2、2。隱藏對手船位、輪流攻擊、重新整理接回對局。正常結束勝者 45 幣、敗者 35 幣；投降無獎勵。
- 7 × 7 墨水大戰，輪流用細筆、濺墨與心形筆刷搶佔畫布。28 手或滿版後結算，勝方 42 幣、另一方 30 幣；平手雙方 32 幣。
- 甜點廚房大作戰：家中廚房入口的 8 回合雙人行動卡小遊戲。兩人各自選料理、支援、惡作劇或防守卡後同步結算；甜點品質、默契與混亂會影響個人金幣與共同銀行獎勵。
- 花園任務：每天最多三次，每次完成三處澆水獲得 25 幣；需移動到指定花圃停留三秒。日期以台灣時間計算。

其他園區小遊戲入口仍是擴充位置，尚未實作對應玩法。

## 操作與建議測試流程

WASD／方向鍵移動、Shift 快走、E 互動、Q／R 旋轉、滾輪縮放；工具列提供全景、日夜、衣櫃與各功能。手機提供虛擬搖桿、互動及鏡頭按鈕。

1. 在兩個獨立瀏覽器工作階段登入不同帳號，確認彼此在線與移動。
2. 購買配件並在衣櫃穿戴，確認另一個畫面更新。
3. 各存入金幣，建立共同目標；80 幣以上的共同家具會送出提案，伴侶同意後才會購買，再進入布置放置與儲存。
4. 開啟海戰棋，兩人配置船隻後輪流攻擊；對局中重新整理仍能接續。
5. 進入家中廚房或工具列開啟甜點廚房，兩邊各選一張行動卡，等同步結算到第 8 回合。
6. 關閉重開瀏覽器，確認造型、錢包、家具與對局仍存在。

## 資料與開發

資料存於 `server/data/state.json`，交易以暫存檔重新命名寫入；備份時先停止伺服器並複製此檔。重啟伺服器後須重新登入，資產與對局不會因此清除。測試使用隔離資料檔，不改動正式測試帳號的資產。

```powershell
node --test tests/store.test.mjs
powershell -ExecutionPolicy Bypass -File tools/build-web.ps1
```

建置使用專案內 Godot 4.7.2 與 `.runtime/Godot/export_templates/4.7.2.stable` 的官方 Web 模板，會重新匯出並壓縮下載檔。修改 GDScript 後需重新建置；只修改 Web 或後端則不需 Godot 匯出，後端修改須重啟 Node。

瀏覽器整合測試為 `tests/browser-smoke.cjs`，需 Playwright 套件及 Chrome，使用 8790 埠。原生 Godot F5 適合預覽場景；完整帳號與經濟系統請由上述 Web 網址進入。

此版是本機開發雛形：固定測試帳號、單一 Node 程序與檔案資料庫，尚未加入正式註冊、跨裝置安全登入、公開部署或 App 封裝。位置同步採基本速度與距離檢查，尚非正式防作弊系統。已用桌面 Chrome 雙工作階段及手機尺寸模擬驗證；實體手機與 Safari 效能仍需測試。

## 對折墨水戰與視窗操作更新

- 關閉互動面板後，鍵盤焦點回到 Godot 畫布；可直接繼續 WASD 移動。
- 網頁工具列換行時，3D 畫面自動使用剩餘視窗空間；窄視窗會調整鏡頭，隱藏重複的 Godot 網頁 HUD。
- 童話調色：鮮綠草地、莓果粉屋頂、青綠水面和明亮日光，沿用現有低負載渲染。
- 工具列「對折墨水戰」：自由畫三個小人、部署陣地、雙方封紙、秘密落墨、鏡射命中與雙向翻紙動畫。
- V2：每半張白紙從 100 × 100 擴為 160 × 110；沒有格線或背景色塊。小人比例從 0.3 縮至 0.12、固定判定半徑從 7 縮至 3，墨點半徑從 3 縮至 1.25；中心距離不超過 4.25 即命中。交戰時不顯示判定圈，繪畫大小不影響公平性。
- 每回合兩人各封一滴墨後一起結算；雙方攻擊都有效後才判勝負，同回合全滅可平手。最多 30 回合，每人有相同攻擊次數，再依命中人數結算。勝方 40、另一方 25，平手各 30 金幣；提前結束不發獎勵。
- 初始站位隨機，可按「換個陣形」重新分布，避免背固定座標。回合戰報顯示命中、擦身而過及雙方命中率，不透露精確落差。
- 未結算的落點只傳給本人；斷線重連後保留已封墨狀態。更新前的未完對局沿用原規則，新局使用 V2。
- 伺服器檢查部署、筆畫、回合與射擊序號，存檔保留未完對局，防止重複結算。
- 驗證：`node --test tests/store.test.mjs`；已安裝 Playwright 時可跑 `node tests/fold-browser.cjs`，使用獨立測試存檔檢查操作焦點、移動、三種視窗、秘密落墨、重連以及雙方全滅平手。

## 明亮田園配色

依照綠草、深綠樹冠、橘棕步道與湖藍水面的參考圖調整 3D 場景：保留石板鋪面，改用暖砂岩色；木構、咖啡廳與動物園棲地同步配色。樹冠使用共用的明暗漸層材質，Web 版保持既有模型數量與低負載設定。已完成 Web 匯出，瀏覽器確認日景、夜景、全景與進出住宅正常且無主控台錯誤。
